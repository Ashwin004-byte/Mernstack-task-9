# MERN Task 9 - Advanced Form Handling & Validation

## Project Overview

This project demonstrates advanced form handling and validation in React using React Hook Form and Yup. The application provides a user registration form with client-side validation to ensure accurate and secure user input.

## Technologies Used

* React.js
* React Hook Form
* Yup
* Vite
* JavaScript
* CSS

## Features Implemented

### Registration Form

* User Name field
* Email field
* Password field
* Confirm Password field

### Validation

* Name is required
* Valid email format required
* Password must contain at least 6 characters
* Confirm Password must match Password

### Error Handling

* Real-time validation messages
* User-friendly error display
* Form submission prevention on invalid input

### Successful Submission

* Success alert message
* Console output of submitted data

## Libraries Used

```bash
npm install react-hook-form
npm install yup
npm install @hookform/resolvers
```

## Learning Outcomes

* Efficient form state management
* Form validation using Yup
* Integration of React Hook Form with Yup Resolver
* Error handling in React forms
* Improved user experience through client-side validation

## Project Outcome

Successfully implemented a validated registration form using React Hook Form and Yup with proper validation rules, error handling, and responsive UI.
